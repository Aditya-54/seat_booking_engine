# AI_USAGE.md

This project was a collaboration between me (Aditya) and an AI assistant (Antigravity, powered by Claude).

The design decisions, business rule reasoning, and trade-off discussions were worked through together. The implementation — engine code, data classes, and test suite — was written collaboratively, with the AI handling code generation based on the design we agreed on. Documentation was drafted by the AI and reviewed by me.

All test results reported in this repository are from actual compilation and execution of the code, not fabricated.
